# Design-user feedback

## User questions

1. What did you expect ExpenseOps to do?
2. What was confusing during setup?
3. Which feature saved you actual time?
4. Which recommendation was wrong or irrelevant?
5. Did anything feel unsafe or surprising?
6. What did you still do manually that you expected the agent to handle?
7. Would you use it next week? Why or why not?
8. Roughly how much time did it save?
